# 🧺 BasketMate 菜篮子

一个专为家庭设计的智能买菜比价与菜谱计划系统。支持多店铺价格对比、自定义菜谱与用餐计划、库存管理，并自动按最低价生成采购清单。数据云端同步，多端访问，让买菜更省心。

## ✨ 核心功能

- **🔍 多店比价**  
  上传超市价格单图片，自动识别或手动录入食材价格。同一食材多家店铺比价，采购时自动分配至最低价店铺。

- **📅 用餐计划**  
  为未来三天制定早餐与正餐计划。早餐转盘随机抽取，正餐根据库存中最早添加的食材智能推荐家常菜。计划所需食材自动汇总。

- **📦 智能采购清单**  
  根据用餐计划与当前库存，自动生成分店铺采购清单。支持临时加菜、加物品，勾选即采购，数量可调。清空功能一键完成剩余项。

- **🥬 库存管理**  
  采购完成后自动更新库存，记录食材添加时间。支持手动调整数量，并按时间或数量排序，方便查看最先需要消耗的食材。

- **📖 菜谱库**  
  内置 50+ 家常菜谱，支持自定义添加、修改、删除。每道菜包含所需食材及用量，计划选择时直接引用。

- **☁️ 多端同步**  
  数据基于 Supabase 云端数据库，登录同一账号即可在手机、平板、电脑间实时同步。

## 🛠️ 技术栈

- **前端框架**：Next.js 15 + React 19 + TypeScript
- **样式**：Tailwind CSS + shadcn/ui
- **状态管理**：React Context + Hooks
- **数据库**：Supabase (PostgreSQL)
- **部署**：Vercel
- **包管理器**：pnpm
