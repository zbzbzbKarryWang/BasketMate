**Assistant**

`run_agent_with_confirmation` 是 **ReAct Agent 的核心执行函数**，负责流式运行 AI 对话并处理用户确认机制。

**主要功能：**

1. **接收用户消息**：接收 LangChain 格式的消息列表（对话历史）
2. **执行 Agent**：调用 LangGraph 的 `create_react_agent` 运行推理
3. **流式输出**：通过异步生成器实时推送事件（SSE 格式）
4. **确认拦截**：遇到 `ask_confirmation` 工具调用时中断，等待用户响应

**推送的事件类型：**

| 事件类型 | 说明 |
|---------|------|
| `thought` | LLM 思考过程的 token（推理片段） |
| `tool_call` | 工具调用开始（名称+参数） |
| `tool_result` | 工具返回结果 |
| `confirmation` | 需要用户确认（流中断） |
| `text` | 最终回答文本 |
| `done` | 流结束 |
| `error` | 错误信息 |

**调用流程：**

```
用户消息 → run_agent_with_confirmation() 
         → Agent 思考（推送 thought）
         → 调用工具（推送 tool_call）
         → 工具返回（推送 tool_result）
         → 如果是 ask_confirmation → 中断，等待用户确认
         → LLM 生成最终答案
         → 推送 done
```

**在项目中的位置：**

- 定义：`backend/app/ai/agent.py` 第 208-344 行
- 调用者：`backend/app/routers/ai_chat.py` 的 `/api/ai/chat` 路由
- 前端通过 SSE 接收事件并展示

简单说：**它是 AI Agent 的"大脑执行器"，负责把用户的问题转化为工具调用，并把结果流式返回给前端。**
